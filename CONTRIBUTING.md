# Contributing Guidelines

Thank you for your interest in contributing to the Personal Finance App Blueprint!

## How to Contribute

1. **Fork the repository**.
2. Create a feature branch: `git checkout -b feature/your-feature-name`.
3. Make your changes.
4. Ensure documentation is clear and follows the existing style.
5. Commit with clear messages (e.g., "Add Open Finance sequence diagram notes").
6. Open a Pull Request.

## Commit Messages

- Use imperative mood: "Add budget alert rules" not "Added...".
- Keep them concise and descriptive.
- Reference related issues if applicable.

## Branching Strategy

- `main`: Stable documentation.
- `feature/*`: New sections or improvements.
- `docs/*`: Documentation-only changes.

## Pull Request Rules

- Describe the changes and motivation.
- Update relevant sections if adding new features.
- Ensure all links and references are valid.
- One logical change per PR when possible.

## Code of Conduct

Be respectful. Focus on improving financial health documentation for users.

## Questions?

Open an issue for discussion.
